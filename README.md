# 电纸书画面管理

面向小米多看电纸书 Pro（Android 8.1）的 LSPosed 模块和管理程序，用于配置锁屏、关机和重启画面。

## 使用

1. 在 LSPosed 中启用模块，作用域只选择“系统框架”，然后重启设备。
2. 打开“电纸书画面管理”，首次同步时在 Magisk 中永久授予 Root。
3. 点“导入图片”，选择“铺满屏幕”“完整显示＋白色填充”或“完整显示＋黑色填充”，然后从系统文件选择器选一张或多张图片。
4. 为每张图片设置启用状态、锁屏/关机/重启用途，以及黑色、白色或关闭锁屏日期。

导入时会读取 EXIF 方向，并按设备物理屏幕处理为 `1404×1872`。铺满模式会居中裁剪；完整显示模式会保留完整画面，并按选择用黑色或白色填补空白。

## 存储结构

- 管理副本：应用私有目录，供预览和继续配置使用。
- 运行时副本：`/data/system/epd-wallpaper/images/`。
- 运行时配置：`/data/system/epd-wallpaper/config.properties`。

运行时副本属于 `system:system`，SELinux 标签为 `system_data_file`。管理程序只在导入、删除或修改配置时通过 Root 原子同步；锁屏 Hook 在 `system_server` 中直接读取系统目录，不通过 Binder 或 ContentProvider 传图。

旧版 `/sdcard/Wallpaper/` 中的图片可以在程序中一次性迁移，源文件不会被删除。

## 安全回退

配置缺失、分类关闭、候选列表为空或图片解码失败时，模块保持系统原画面。系统自带图片不能删除，但可以逐张禁用。
